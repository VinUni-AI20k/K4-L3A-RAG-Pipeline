## Kiểm thử và kết quả

- **Test hoặc query tôi đã dùng:** 
  1. Cấu hình file danh sách nguồn đầu vào tại `data/legal_urls.csv` và `data/news_urls.csv`.
  2. Chạy tự động hóa đăng nhập và thu thập tài liệu pháp luật: 
     `python3 -m src.task1_collect_legal_docs`
  3. Chạy thu thập bài viết tin tức du lịch: 
     `python3 -m src.task2_crawl_news`
  4. Chạy pipeline chuẩn hóa Markdown toàn bộ corpus: 
     `python3 -m src.task3_convert_markdown`
  5. Kiểm tra tính idempotency bằng cách chạy lại lệnh task 3 lần thứ hai để kiểm tra cơ chế kiểm tra thời gian chỉnh sửa file (`st_mtime` check) chống tạo file trùng lặp.
- **Kết quả trước/sau nếu có:** 
  - *Trước:* Playwright bị kẹt do không tìm thấy form đăng nhập nằm trong Iframe hoặc bị lỗi `strict mode violation` do trùng lặp element; file `.doc` bị MarkItDown từ chối xử lý (`MissingDependencyException`); chạy lại script bị ghi đè toàn bộ tốn thời gian. 
  - *Sau:* Hệ thống tự động điền form, vượt Iframe và tải thành công các tài liệu tiếng Việt về đúng thư mục `data/landing/legal/`. 100% tài liệu được convert sang `.md` sạch sẽ với đầy đủ metadata header; các lần chạy lại sau tự động bỏ qua các file chưa thay đổi (`st_mtime` check) với thời gian thực thi gần như tức thì (~0s).
- **Lỗi đã phát hiện và cách xử lý:** 
  - *Lỗi 1:* Playwright báo lỗi timeout do cố tìm kiếm element của form đăng nhập ở ngoài Main Frame. 
    *Cách xử lý:* Sử dụng `page.frame_locator("iframe[title='LuatVietnam Single Sign On']")` để định đúng phạm vi cần thao tác.
  - *Lỗi 2:* Lỗi `Element is not visible` khi click vào nút tải file do nút nằm trong tab ẩn chưa kích hoạt trên UI. 
    *Cách xử lý:* Sử dụng lệnh thực thi JavaScript trực tiếp trên element (`target_link.evaluate("el => el.click()")`) để ép trình duyệt kích hoạt tải file bỏ qua kiểm tra hiển thị.
