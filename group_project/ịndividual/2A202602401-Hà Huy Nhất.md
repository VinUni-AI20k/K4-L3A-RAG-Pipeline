## Quyết định kỹ thuật quan trọng

1. **Quyết định:** Từ chối trả lời (Safe refusal) nếu điểm cosine của tài liệu tìm được quá thấp (ngưỡng 0.3).
   **Lý do/evidence:** Nếu người dùng hỏi những câu ngoài luồng (như "giá vàng hôm nay") thì hệ thống vẫn lấy đại một đoạn văn không liên quan lên làm context. LLM rất hay lanh chanh tự trả lời bằng kiến thức có sẵn dẫn đến báo cáo sai sự thật. Tôi code logic bắt chặt: tài liệu tìm được phải đạt điểm > 0.3 mới cho trả lời, không thì ngắt luôn và báo "Không đủ thông tin".
   **Trade-off:** Trải nghiệm người dùng đôi lúc hơi cứng nhắc vì bot hay kêu "không biết", nhưng bù lại tính trung thực (Faithfulness) rất cao.

2. **Quyết định:** Dùng API Gemini Vision để OCR đọc file PDF quét ảnh.
   **Lý do/evidence:** Thử xài PyMuPDF để trích xuất 3 file công văn tuyển sinh của PTIT thì lấy ra được 0 chữ (do trường up toàn file scan đóng dấu đỏ, bản chất là ảnh). Tôi buộc phải viết script cắt ảnh truyền qua API Gemini để AI đọc giùm ra text.
   **Trade-off:** Quá trình chuẩn hóa dữ liệu chạy rất lâu, hay bị văng lỗi Rate Limit của nền tảng, phải chạy lại mấy lần mới full 100% trang, bù lại text lấy ra cực kỳ đẹp và đầy đủ.
